Cómo Ingresar
Para ingresar a éste nuevo portal debes:

1.   Ingresar el usuario
2.   Ingresar el número del token
3.   Haga clic en la cajita para aceptar las condiciones de seguridad y se habilite el botón

Administración – Configuración de Usuarios
Para realizar la modificación o creación de usuarios secundarios, se ingresa a:

Ruta: Administración / Usuarios / Configuración de Usuarios


<!-- página 4 -->

Configuración de Usuarios - Crear
Para crear un usuario secundario debe:
1. Dar clic en Crear Nuevo.
2. Diligenciar la información que aparece en pantalla, los campos que están en color amarillo son obligatorios.
Posterior a esto, deberá asignar productos, topes, revisar los horarios y por último generar la contraseña.


<!-- página 5 -->

Configuración de Usuarios – Modificar – Paso 1
Para realizar la modificación de un usuario secundario debe:
1. Consultar el usuario, esto lo podrá realizar a través de una de las opciones que se presentan en pantalla.
2. Dar clic en el ícono «configurar y modificar».


<!-- página 6 -->

Configuración de Usuarios – Modificar – Paso 2
Se debe ingresar en cada una de las pestañas que se describen en la pantalla:

1.   Asignar Productos: se debe habilitar los productos que el usuario secundario requiera para operar en el
     canal. Es importante mencionar que cada vez que la empresa abra algún producto con el Banco, el
     usuario administrador debe habilitar dicho producto a la empresa y luego lo debe habilitar al usuario
     respectivo.


<!-- página 7 -->

Configuración de Usuarios – Modificar – Paso 2.1
2. Asignar Topes: se debe registrar los montos que el usuario secundario tendrá habilitado por cada uno de los
servicios/archivos y sobre los productos asignados.


<!-- página 8 -->

Configuración de Usuarios – Modificar – Paso 2.2
3. Días y Horarios: es el horario con el cual el usuario secundario podría ingresar al portal, por defecto tendrá
los horarios de la empresa; estos podrían modificarse siempre y cuando no exceden los establecidos para la
empresa.


<!-- página 9 -->

Configuración de Usuarios – Modificar – Paso 2.3
4. Contraseña: es la opción para generar la clave para que el usuario secundario pueda ingresar al portal.
