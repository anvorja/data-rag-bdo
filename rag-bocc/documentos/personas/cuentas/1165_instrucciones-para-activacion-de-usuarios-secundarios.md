# Instrucciones para activación de usuarios secundarios

<!-- página 1 -->

      Instrucciones para activación de usuarios secundarios
   Para activar o inactivar usuarios secundarios, ingreso al módulo de Administración y realizo clic en la
1. sección de Activación/Inactivación.


<!-- página 2 -->

        Instrucciones para activación de usuarios secundarios
2. En la sección de Activación/Inactivación, están los diferentes parámetros de consulta por los cuales se
   puede filtrar el usuario que deseo activar o inactivar.


              0,0%


<!-- página 3 -->

        Instrucciones para activación de usuarios secundarios

3. Selecciono el parámetro de consulta, en este caso por usuario inactivo y selecciono la opción de
    consultar.


<!-- página 4 -->

       Instrucciones para activación de usuarios secundarios
4. Al seleccionar consultar, aparecerán todos los usuarios que tienen estado inactivo. Selecciono al
   usuario secundario que deseo activar.


  5.   Con el usuario seleccionado, se da clic en Cambiar
       Estado de Usuario(s)


<!-- página 5 -->

       Instrucciones para activación de usuarios secundarios

6. Cuando   se cambia el estado del usuario, se debe de ingresar la clave y acepto y confirmo la
   transacción.


<!-- página 6 -->

        Instrucciones para activación de usuarios secundarios

7. Finalizo la transacción, la cual estará pendiente por ser autorizada de parte del usuario administrador.
   Hago clic en finalizar.
